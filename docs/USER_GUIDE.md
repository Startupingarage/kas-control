# Кас — пульт для Windows

Приложение выбирает проект и разговор ChatGPT, к которому подключается колонка.
Оно не меняет голос, модель, громкость, мимику или инструкции проекта.

Перед первым запуском на новом ПК или устройстве прочитайте
[предварительные условия и ссылки на внешние проекты](PREREQUISITES.md).
Получение root и установка голосового клиента выполняются отдельно от пульта.

## Запуск

Откройте `KasControl.exe` или ярлык «Кас — пульт» на рабочем столе.
Установка Python не требуется. Это персональная сборка для текущего компьютера:
используется уже настроенный WSL `StationLab`, пользователь `stationuser` и SSH
профиль `/home/stationuser/kas-live/ssh_config` с узлом `station`.

Для получения списков ChatGPT нужен работающий интернет/VPN на ПК. Колонка должна
быть доступна по существующему SSH-профилю. Пароль в приложение вводить не нужно.
Сессия аккаунта читается с колонки в память; токены в комплект не включены.

Если доступ к списку отклонён, нажмите «Войти в ChatGPT» в левой панели.
В отдельном веб-окне войдите в тот же аккаунт, что используется колонкой.
После подтверждения окно скроется, списки обновятся автоматически. Крестик
скрывает веб-окно, сохраняя сессию; во время незавершённого входа он отменяет
ожидание. Для этого режима списки и создание проектов выполняются
через веб-сессию окна, а голосовой клиент колонки не перезапускается.
Профиль входа сохраняется средствами WebView2 в `%LOCALAPPDATA%\KasControl\WebView2`.
Пароль не запрашивается пультом и не входит в поставку. При запуске пульта
сохранённый веб-профиль подключается автоматически. Если сессия закончилась,
нажмите кнопку входа. Проверка браузера
или недоступность ChatGPT по сети могут потребовать действий в веб-окне.

## Использование

1. Выберите проект слева. Поле над списком фильтрует названия.
2. Выберите чат справа и нажмите «Подключить Каса».
3. Нажмите «Новый чат», выберите проект в списке и введите название.
   По умолчанию выбран текущий проект. Чат подготавливается в каталоге колонки;
   текущий разговор не переключается. Подключение — отдельная кнопка.
   В этом же окне можно сразу заполнить «Фраза вызова (необязательно)»:
   чат и команда сохраняются вместе. Если фраза занята или зарезервирована,
   новый чат не создаётся. Пустое поле оставляет создание без команды.
4. «Открыть чат» открывает выбранный разговор в ChatGPT в обычном браузере.
5. «Закрыть сеанс» завершает голосовой разговор. «Обновить» перечитывает состояние.
6. «Создать проект» создаёт пустой проект в текущем аккаунте ChatGPT.
7. Выберите существующий или только что подготовленный чат, введите фразу,
   например `открой кулинарный чат`, и нажмите «Сохранить».
   Затем произнесите «Алиса, открой кулинарный чат».
   Если слово пробуждения колонки — «Яндекс», используйте его.
8. «Все команды» показывает назначенные чаты и оставшиеся штатные команды.
   «Убрать команду» удаляет только привязку фразы, не сам разговор.

Для всех проектов действуют общие команды закрытия: «Алиса, закрой чат»,
«Алиса, заверши чат» и «Алиса, хватит». Они завершают текущий голосовой сеанс,
не удаляют историю и не требуют отдельной настройки для каждого разговора.

Название нового чата является локальным названием привязки; сервер ChatGPT может
показать автоматически сформированный заголовок. История старого чата сохраняется,
но не копируется в новый. Инструкции и политика памяти берутся из выбранного проекта.
Новый разговор отсутствует в серверном списке до первого подключения и реплики.
В пульте он помечен «Подготовлен»: команду можно назначить сразу, без разговора
и запуска Voice. После каждого изменения состояние автоматически перечитывается.
Если чтение не удалось, пульт явно показывает устаревший статус.

Автоматическая отправка `.` для немедленного создания облачного чата проверена,
но текущая сессия требует браузерную проверку Sentinel. Сообщение не отправляется.
Подготовленный чат не выдаётся за сохранённый в облаке; команда для него уже работает.
Удаления чатов и настройки памяти в пульте нет. Новые проекты создаются с пустыми
инструкциями и серверными настройками памяти по умолчанию; их можно настроить в ChatGPT.

Одна фраза ведёт в один конкретный чат. Повторное назначение для этого чата заменяет
его прежнюю фразу. Фразу другого чата нельзя незаметно перезаписать: сначала уберите
прежнюю привязку. Команды закрытия, нового и предыдущего чата зарезервированы.
Автоматического создания чатов по всем проектам нет; «1С» не получает автоматических
привязок. Любое назначение выполняется только по явному выбору в пульте.

Создание проекта, подготовка чата и сохранение фразы не запускают и не перезапускают
голос. При первом подключении используется регистрация с резервной копией.
Подтверждение сохранения команды означает, что обработчик
колонки прочитал именно сохранённую версию команд, а не только запись файла на ПК.

При смене привязки клиент кратко переподключается: приложение сохраняет настройки,
перезапускает тот же бинарник и проверяет новый сеанс. Повторный выбор уже активного
текущего чата не перезапускает его. Готовность подтверждается состоянием `active`.
Не запускайте переключение во время важной реплики: текущий разговор завершится.

После закрытия приложения или выключения ПК голос продолжает работать на колонке.
Приложение не является голосовым мостом и не обязано постоянно работать.
Обработчик фраз установлен отдельно на колонке в `/data/opt/kas-command-router/`.
Его автозапуск — `/etc/init.d/S99zkasroutes`. Для выполнения назначенных команд
пульт, Windows и WSL не нужны. В поставке нет изменения голосового бинарника,
модели или параметров звука.

## Возврат

«Вернуть привязку» восстанавливает настройки перед последним переключением.
При неудачном запуске новой привязки выполняется автоматический возврат.
Настройки сохраняются на колонке в `/data/opt/kas-control-backups/` с правами
владельца. Файл `LATEST` указывает на последний комплект; `restore.sh` внутри
комплекта выполняет ручное восстановление. Бинарник Voice не заменяется.

Если сеть пропала во время операции, дождитесь её восстановления и обновите
состояние. Нельзя считать откат подтверждённым, пока колонка недоступна.
После принудительного завершения приложения блокировка ядра не остаётся навсегда.
Для полного отключения новых голосовых команд запустите рядом с пультом
`Отключить голосовые команды.cmd`. Это удалит только автозапуск обработчика,
остановит его и вернёт прежние штатные фразы. Текущий чат и голос не меняются.
Сами настройки команд сохраняются на колонке для восстановления.

## Ограничения

Используются существующие веб-интерфейсы ChatGPT; они могут измениться. Ошибка
доступа к спискам останавливает подготовку до изменений на колонке. Новых входов,
покупок, API-ключей или автопополнения приложение не выполняет.

Сборка не подписана сертификатом издателя. Это локальный персональный инструмент,
а не универсальный установщик для других компьютеров или аккаунтов.
Физическое распознавание произнесённой фразы и запуск после полной перезагрузки
проверяются отдельно от тестов кода и наличия файла автозапуска.

## Разработка

`backend.py` — доступ к аккаунту/колонке и восстановимая транзакция.
`desktop.py` — WebView2 с ограниченным native bridge, `frontend/` — React и Base UI,
`management.py` — управление каталогом. `app.py` — прежний Tkinter-интерфейс.
`build-modern.ps1` собирает новый EXE в отдельном окружении `.venv`.
`test_backend.py`, `test_transaction.py`, `test_ui.py`
проверяют преобразования, ошибки, настоящую shell-транзакцию на имитации в WSL
и интерфейс без обращения к колонке. `preview_desktop.py` создаёт снимок интерфейса
на отдельном рабочем столе, не переключая пользовательский экран.

Для диагностического чтения собранным приложением:
`KasControl.exe --check C:\path\check.json`.
Эта проверка не меняет привязку; отчёт не содержит токенов или текста разговоров.

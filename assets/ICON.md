# Windows icon

Current source is kas-control.png, a transparent raster asset derived from the
user's three-dimensional green droid reference using the built-in imagegen tool.
kas-control.ico contains 16, 24, 32, 48, 64, 128 and 256 pixel representations.
The old SVG and frontend/render-icon.mjs are historical vector experiments;
do not regenerate the current PNG from that SVG.

Prompt: Extract precisely the photorealistic dark green spherical droid from
the reference as a Windows application icon asset. Preserve the same 3D robot,
dome shape, head angle, camera eye placement, antennae, body panel geometry,
green circular body light and metallic rim lighting. Remove text, background,
floor and external shadow. Transparent square image, centered full robot,
small clear margins. No vector, cartoon, outline or flat-shape redrawing.
